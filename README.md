## ⚠️ Disclaimer

> **This is an AI decision-support research prototype, NOT an official warning system.**
> All predictions are generated by AI models and should not be used for operational decision-making.
> This system must not replace official advisories issued by the India Meteorological Department (IMD) or other authorized agencies.

## 🎯 Features

| Capability | Description |
|---|---|
| **Cyclone Detection** | CNN-based detection from multi-channel satellite imagery |
| **IMD Classification** | 9-class cyclone stage classification (Low Pressure → Super Cyclonic Storm) |
| **Intensity Estimation** | Wind speed (km/h) and pressure (hPa) regression with uncertainty |
| **Track Forecasting** | Multi-horizon trajectory prediction (+6/12/24/48h) via LSTM+CNN fusion |
| **Rapid Intensification** | RI probability estimation |
| **Uncertainty Quantification** | Monte Carlo Dropout confidence intervals |
| **Explainable AI** | Grad-CAM heatmaps showing model attention regions |
| **Risk Assessment** | Rules-based multi-factor risk engine with alert levels |
| **Interactive Map** | Leaflet-based dark-mode cyclone track visualization |
| **Dataset Registry** | Tracking IBTrACS, TCIR, ERA5, GPM IMERG data sources |

## 🚀 Quick Start

### Prerequisites

- **Python 3.11+** with pip
- **Node.js 18+** with npm
- (Optional) **Docker** for containerized deployment

### 1. Clone & Setup

```bash
git clone <repository-url>
cd cyclone-ai

# Copy environment config
cp .env.example .env
```

### 2. Install Backend Dependencies

```bash
pip install -r backend/requirements.txt
```

### 3. Install Frontend Dependencies

```bash
cd frontend
npm install
cd ..
```

### 4. Generate Demo Data (if not present)

```bash
python scripts/generate_sample_data.py
```

### 5. Start Development Servers

**Option A: Using start scripts**
```powershell
# Windows
.\start.ps1 -Mode dev

# Linux/macOS
./start.sh dev
```

**Option B: Manual**
```bash
# Terminal 1 — Backend
python -m uvicorn backend.app.main:app --reload --port 8000

# Terminal 2 — Frontend
cd frontend && npm run dev
```

### 6. Open in Browser

- **Frontend**: http://localhost:5173
- **API Docs**: http://localhost:8000/docs
- **ReDoc**: http://localhost:8000/redoc

## 🐳 Docker Deployment

```bash
# Build and start
docker compose up --build

# Or in background
docker compose up -d --build

# View logs
docker compose logs -f cyclone-ai

# Stop
docker compose down
```

The app will be available at **http://localhost:8000** with the React frontend served from FastAPI.

## 🔧 Production Build (No Docker)

```bash
# Build frontend
cd frontend && npm run build && cd ..

# Start production server (serves frontend + API from port 8000)
SERVE_FRONTEND=true python backend/run.py

# Or on Windows:
$env:SERVE_FRONTEND="true"; python backend/run.py
```

## 🧠 ML Models

All models use **baseline (randomly initialized) weights** by default. They produce structurally valid outputs but are not trained on real cyclone data. To use trained models, place checkpoint files in `models/checkpoints/`:

| Model | File | Architecture |
|-------|------|-------------|
| Detector | `detector.pt` | CNN + classification + localization heads |
| Classifier | `classifier.pt` | CNN + 9-class IMD classification head |
| Intensity | `intensity.pt` | CNN + MLP fusion, wind/pressure regression |
| Track Predictor | `track.pt` | LSTM + CNN + MLP, multi-horizon trajectory |
